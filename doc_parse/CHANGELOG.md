# Changelog

- Defined as a testnet draft, replacing the field extraction draft (doc_extract). Field extraction returns later as an arena built on top of this one, taking the parsed Markdown as its input.
- Envelope group mt-5 with max input 4,096 and output 2,048 tokens and the class's page image limits (2,048 px long side, one page per call, 15 s per page at p95). The edge bonus applies, so a system that also passes mt-3 (CPU) or mt-2 (Phone) earns up to 0.20. Envelope classes version 4 adds image limits to every open class and removes the 1B floor from mt-5, so granite-docling (258M) and PaddleOCR-VL (0.9B) can compete on the GPU class.
- Bases: Qwen3-VL 4B (reference) and 2B, DeepSeek-OCR, PaddleOCR-VL and granite-docling, all Apache 2.0 or MIT, checked 2026-10-25. Excluded: Qwen2.5-VL-3B and Nanonets-OCR2-3B (non commercial), MinerU2.5 (AGPL), and olmOCR 2, Qwen2.5-VL-7B and Qwen3-VL-8B (above the 8B cap of mt-5).
- Item pass line is 0.85. Checks follow olmOCR-Bench but cover the whole reading order, score tables with TEDS, and penalise hallucinated text. Calibration against the reference model and a frontier model happens before the arena goes live.
- Training data: olmOCR-mix-1025 (ODC-BY; the card says it is intended for research and educational use, which is a statement of intent rather than a licence term, to be confirmed with Ai2), DocLayNet v1.1 (CDLA Permissive 1.0), olmOCR-Bench (ODC-BY), PubTabNet (CDLA Permissive 1.0), VRDU, CORD v2 and FATURA (CC BY 4.0). FinTabNet's licence is still to confirm. OmniDocBench is research only and is never used for grading.
- Hidden items each epoch are generated fresh: documents written as HTML or LaTeX (invoices, financial statements with complex tables, contracts, forms, pages with equations, charts drawn from known data, several languages), rendered to page images with scan damage (blur, tilt, low resolution, stamps), so the ground truth comes from the source and nothing can be memorised; plus a small slice of real public documents released after the commit window, labelled by hand.
- Still to build before it goes live: image input in the validator sandbox (vLLM multimodal, provenance for vision models), the `page_parsing` grader (edit distance, Kendall's tau order, TEDS, LaTeX and chart matching, hallucination), the twin generator (same source, other render), the hidden page generator, lower class tests with GGUF vision support in llama.cpp, and calibration of the 0.85 line.
