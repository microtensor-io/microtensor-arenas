# Changelog

- Replaces session titling (cc_aside_s1). Envelope group mt-3 with max output 3,072 and max input 29,696 tokens, so Qwen2.5's 32,768 token window holds both. Bases Qwen2.5 Coder 7B and 1.5B and Phi 4 mini. Escalation through the relay (Claude Haiku 5.5, GLM 5.3 Flash) until frontier models are served on our network. Empty pools burn.
- Testnet runs on a 100 item hidden set: 100 items each for SLM, harness, escalation and system, 60 for the router, and a pool is paid from 100 items (`scoring.min_items`). Mainnet returns to 400.
- Envelope classes version 2: the Small GPU class is now mt-5 (it was mt-3), with the same limits.
- Testnet item pass line is 0.50. Calibration with the untrained reference Qwen2.5 Coder 7B on 200 dev items passed 37.5% at 0.50, 21% at 0.60, 8% at 0.70 and 3.5% at 0.80 (mean item score 0.449). The mainnet line is set later from a frontier model and trained miners.
- Renamed from ctx_compress_s1. An arena runs on testnet or mainnet.
- Miner mode evaluation: miners run their own evaluation on hardware profile P1 (RTX 4090) inside the pinned images and upload a transcript; validators replay it on CPU, spot check at least 200 SLM calls per sampled miner and grade with a 0.5B GGUF probe. The settle margin rises to 1,800 blocks (6 h) so grading fits. The runner, replayer and pinned llama.cpp image digests are placeholders until those images are built.
- v2: Compaction is redefined around the gateway `compaction` request kind. Base changes from Qwen2.5 Coder 7B to Granite 4.0 H Micro so 120K inputs fit a 24 GB card. Output changes from JSON to the agent's nine heading markdown. Dataset changes from SWE agent trajectories to our own recorded agent sessions, which also removes the Llama naming condition. Resume gate added at miner level, pass line raised to 0.60, spot check reduced to 40 calls, probe raised to 1.5B, serving priced flat at $0.005 per compaction. Qwen3 4B Instruct 2507 was evaluated and set aside: 11.8 GB of KV at 160K even in fp8 and quadratic attention over 36 layers.
- Dataset: generated agent sessions at microtensor-io/agent-sessions. `mta dev` builds dev items and `mta hidden` builds hidden items from a secret seed with the session generator; token counts use the Granite tokenizer.
- Evaluation text: the coordinator's spot check of 40 calls with 10 timed, evidence from two agreeing runs, the ban and appeal, the duplicate rule and at most 3 uploads per epoch. There is no resume gate: no agent is pinned and no code runs one.
- Serving list price lowered from $0.005 to $0.001 per compaction, which is about $0.015 per million input tokens on a typical 67,000 token session.
- Serving is priced per token instead of flat per compaction: $0.01 per million input tokens and output tokens free. A typical 67,000 token session costs about $0.0007 and a full 122,880 token session about $0.0012.
