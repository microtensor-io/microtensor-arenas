# Dataset

[microtensor-io/agent-sessions](https://huggingface.co/datasets/microtensor-io/agent-sessions)

Licence: Microtensor dataset terms

Coding agent sessions generated by Microtensor: a coined Python project with one injected bug, worked by a scripted agent whose every tool result is the real output of the real command, recorded in the Anthropic Messages shape and rendered canonically. The public dev split holds 2,000 sessions; hidden items come from the same generator under a secret seed and never leave validators.

Build more dev items in the arena's exact format with

```
pip install -e '.[compress]'
mta dev --arena ctx_compress --count 1000 --seed 7 --out data/dev
mta check data/dev
```
